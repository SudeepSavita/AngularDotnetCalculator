📋 Project Flow — How It Works

This project is a full-stack Scientific Calculator web application. Below is a complete step-by-step explanation of how the application works from the moment a user presses a button to the moment the result appears on the screen.

1
User Interaction — Angular Frontend (UI Layer)

The user opens the application in a web browser at http://localhost:5000. The interface shows a mobile phone-style calculator rendered entirely in the browser using Angular 17. When the user presses any button (number, operator, or function), the Angular component immediately updates the expression shown in the display area. This happens instantly in real time — no page reload is required. The user can also type directly using the keyboard (numbers, +, -, *, /, Enter, Backspace, Escape).

↓
2
Input Validation — Frontend Guard (TypeScript Logic)

Before the expression is sent to the server, the Angular component runs a series of validation checks in TypeScript to catch obvious errors immediately without wasting a network call. These checks include: (a) Balanced parentheses — every opening ( must have a matching closing ). (b) No empty parentheses like (). (c) No operator at the very start (e.g. +5 is invalid). (d) No operator at the end (e.g. 5+ is invalid). (e) No consecutive operators (e.g. 5++3 — the second operator automatically replaces the first). (f) No double factorial !!. (g) No deeply nested parentheses beyond 10 levels. (h) No excessively long power chains like ^2^2^2^2^2. If any check fails, a red Format Error message is shown in the display with a shake animation — no server call is made.

↓
3
HTTP API Call — Angular HttpClient to ASP.NET Core

If the expression passes all frontend validations, Angular sends an HTTP POST request to the backend API endpoint /api/calculator/evaluate. The request body is a JSON object containing two fields: expression (the mathematical string entered by the user) and isDegrees (a boolean flag indicating whether trigonometric functions should use degrees or radians). This communication follows the REST API standard using JSON format. The Angular HttpClient service handles this asynchronously — the UI remains fully responsive while waiting for the response.

↓
4
Backend Reception — ASP.NET Core Web API Controller

The ASP.NET Core 8 server receives the HTTP POST request in the CalculatorController.cs file. The controller's Evaluate action method deserializes the JSON body into a C# record EvaluateRequest. The controller is decorated with [ApiController] and [Route("api/[controller]")] attributes which handle routing automatically. The entire request is wrapped in a try-catch block so that any unexpected mathematical or parsing error is caught gracefully and returned as a structured JSON error response instead of crashing the server.

↓
5
Expression Pre-Processing — C# Math Engine

The raw expression string goes through a multi-stage pre-processing pipeline written in C#: (a) Constants — pi and π are replaced with 3.14159265358979..., and standalone e is replaced with 2.71828182845904.... (b) Factorial — patterns like 5! are detected using Regex and computed directly (supports 0! to 20!). (c) Trigonometric functions — sin(, cos(, tan( are found using recursive string scanning, their inner expressions are evaluated first, and the result replaces the function call. If isDegrees is true, angles are converted from degrees to radians before calling Math.Sin/Cos/Tan. (d) Logarithms — log( calls Math.Log10 and ln( calls Math.Log. (e) Square root — sqrt( calls Math.Sqrt. Negative inputs throw an exception. (f) Power operator — ^ is replaced by evaluating Math.Pow(base, exponent) using Regex pattern matching. Exponents above 300 are rejected to prevent overflow.

↓
6
Final Evaluation — DataTable.Compute()

After all functions and constants are resolved, the expression is reduced to a pure arithmetic string containing only numbers and basic operators (+, -, *, /). This is then evaluated using System.Data.DataTable.Compute() — a built-in .NET method that safely evaluates arithmetic expressions without using eval() or any script engine. This approach is secure and handles operator precedence (BODMAS/PEMDAS) correctly. The result is then validated: if it is NaN, Infinity, or larger than 10⁹⁹, it is treated as an error.

↓
7
Response & Display — Result Back to Angular

The backend returns a JSON response: { "result": "42", "error": null } for success, or { "result": null, "error": "Format Error" } for failure. Angular's HttpClient receives this response. If successful, the result is displayed in the result line of the calculator display in purple. The expression moves to the smaller top line as history. If there is an error, Format Error is shown in red with a shake animation. The user can then continue by pressing more buttons — the expression remains editable.

⚙️ Technologies Used

This project uses a modern full-stack architecture combining a JavaScript frontend framework with a .NET backend. No CSS framework was used — all styling is hand-written custom CSS.

🖥️ Frontend
🅰️ Angular 17

Angular is a TypeScript-based open-source web application framework developed by Google. In this project, Angular 17 is used with standalone components — meaning no NgModule is required. The CalculatorComponent handles all UI rendering, button interactions, expression building, and validation. The AppComponent hosts the navbar and modal. Angular's two-way data binding and interpolation (double curly braces with variable name) ensure the display updates in real time as the user types.

📘 TypeScript

TypeScript is a strongly-typed superset of JavaScript. It adds compile-time type checking which prevents runtime errors. In this project, TypeScript is used for all component logic: the press(), calculate(), validate(), and backspace() methods are all written in TypeScript. The CalcResponse interface defines the exact shape of the API response, ensuring type safety when handling the result.

🎨 Custom CSS3

All visual styling is written entirely in hand-crafted CSS3 — no Bootstrap, no Tailwind, no UI library. The design features a pastel light theme for the phone frame and screen, a warm white display area, glassmorphism effects (backdrop-filter: blur), CSS gradients for buttons, CSS animations (shake effect for errors), CSS Grid for button layout, and CSS custom properties for consistent theming. The design is fully responsive and works on mobile screens as well.

📡 Angular HttpClient

Angular's built-in HttpClient module is used to make HTTP requests to the ASP.NET Core API. The http.post() method sends the expression asynchronously and the .subscribe() callback handles both success and error responses. This follows the Observer pattern using RxJS Observables, which is Angular's recommended approach for handling asynchronous HTTP communication.

🖧 Backend
⚡ ASP.NET Core 8

ASP.NET Core is Microsoft's high-performance, cross-platform web framework for building modern web APIs. In this project, it serves two purposes: (1) It hosts the REST API at /api/calculator/evaluate which processes mathematical expressions. (2) It serves the Angular static files (HTML, JS, CSS) from the wwwroot/ folder and falls back to index.html for all routes so Angular's client-side routing works correctly. CORS is also configured to allow the Angular dev server (localhost:4200) to communicate with the API during development.

🔷 C# 12

C# is Microsoft's modern, object-oriented programming language. The backend logic is written entirely in C#. Key features used include: Record types (EvaluateRequest) for clean data models, Pattern matching and Regular Expressions (System.Text.RegularExpressions) for parsing mathematical expressions, Lambda expressions for passing math functions as parameters, and Exception handling (try-catch) for graceful error responses. The Math class provides all scientific functions.

📦 .NET 8

.NET 8 is the latest Long-Term Support (LTS) version of Microsoft's development platform. It provides the runtime environment, base class libraries (including System.Data.DataTable used for expression evaluation), and the hosting infrastructure for the web server. The project targets net8.0 and uses the minimal hosting model with WebApplication.CreateBuilder().

🗃️ DataTable.Compute()

System.Data.DataTable.Compute(expression, filter) is a .NET built-in method originally designed for filtering DataTable rows. However, it also functions as a safe arithmetic expression evaluator. It correctly handles operator precedence (BODMAS), parentheses, and all four basic operators. It is used here as a secure alternative to eval() — it cannot execute arbitrary code, only evaluate pure mathematical arithmetic.

📖 Complete User Guide

This guide explains every button and feature of the Scientific Calculator in detail. Read this to understand how to use every function correctly.

🖥️ Display Area

The calculator display has two lines. The top line (smaller, grey text) shows the expression you are currently building — for example sin(45)+sqrt(16). The bottom line (larger, purple text) shows the result after you press =. If there is a Format Error, it appears in red on the bottom line and shakes to alert you. The display always shows 0 when empty.

🔢 Number Buttons (0–9) and Decimal Point (.)

Press any number button to add digits to your expression. Press . to add a decimal point. The calculator prevents entering two decimal points in the same number (e.g. 3..14 is blocked). After pressing = and getting a result, if you press a number, a fresh expression starts. If you press an operator after =, the calculation continues from the result.

➕ ➖ ✖️ ➗ Arithmetic Operators

The four basic operators are: + (add), − (subtract), × (multiply shown as *, sent to API), ÷ (divide shown as ÷, sent as /). If you press two operators in a row (e.g. press + then −), the second one automatically replaces the first — you will see 5− not 5+−. This prevents invalid expressions.

📐 Trigonometric Functions — sin, cos, tan

sin calculates the sine of an angle. cos calculates the cosine. tan calculates the tangent. By default, angles are in degrees. Example: Press sin( → type 30 → press ) → press = → result is 0.5. Note: tan(90) is undefined (infinity) and will show Format Error.

📊 Logarithm Functions — log and ln

log computes the base-10 logarithm. Example: log(100) = 2. ln computes the natural logarithm (base e). Example: ln(e) = 1. Both functions require a positive number inside the parentheses. Entering log(-5) or log(0) will show Format Error.

√ Square Root

Press √ to open a square root function. Type the number inside, then close with ) and press =. Example: sqrt(144) = 12. You can nest it: sqrt(2+14) = 4. Negative numbers inside sqrt will show Format Error.

x² and xʸ — Power Functions

x² appends ^2 to square the current number. Example: type 9 → press x² → expression becomes 9^2 → press = → result is 81. xʸ appends ^ so you can type your own exponent. Example: 2^10 = 1024. Exponents above 300 are blocked to prevent overflow.

π and e — Mathematical Constants

π inserts the value of Pi (3.14159265358979...). Example: 2*pi gives the circumference ratio. e inserts Euler's number (2.71828182845904...). Example: ln(e) = 1. These constants are replaced with their full numeric values before evaluation.

n! — Factorial

Press a number then n! to compute its factorial. Example: 5! = 120 (because 5×4×3×2×1=120). Maximum supported value is 20! = 2,432,902,008,176,640,000. Factorial of negative or decimal numbers shows Format Error. You cannot press ! twice in a row or after an operator.

( ) — Parentheses / Grouping

Use parentheses to group parts of an expression and control calculation order. Example: (2+3)*4 = 20, but 2+3*4 = 14 (multiplication first by BODMAS). The calculator prevents closing a parenthesis if there is no matching open parenthesis. Nested parentheses up to 10 levels deep are supported.

AC — All Clear

Pressing AC (All Clear) completely resets the calculator — the expression is cleared, the result is cleared, and the display returns to 0. Use this whenever you want to start a brand new calculation from scratch.

⌫ — Backspace / Delete

Pressing ⌫ removes the last character from the expression. This is useful if you pressed a wrong button. If you have just seen a result (after pressing =), pressing backspace clears everything (same as AC in that state).
